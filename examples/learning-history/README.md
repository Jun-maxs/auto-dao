## 新版样例说明

`new-version-stm32-spi-mini_2026-04-18` 是推荐入口。它不是完整课程包，而是公开仓库友好的裁剪版：

- PDF：完整版会保留原始学习资料；仓库样例只保留 `examples/sources/...` 形式的占位路径。
- 图片：完整版可能包含 PDF/OCR/课程图示导出的图片目录；仓库样例不提交这些二进制资产。
- 私有路径：完整版可能引用个人资料库、源码工程或板卡实验路径；仓库样例全部脱敏。
- 大目录：完整版可能包含转换全文、模型 JSON、图片缓存、互动 HTML、源码索引；仓库样例只保留能说明结构的 Markdown/JSON。

## 学习类型说明

### 人文社科类
学习哲学、心理学、社会学等领域的书籍，注重概念理解和思想探讨。

### 理科类
学习数学、物理等基础学科教材，注重定理推导和习题练习。

### 工科论文
学习机器学习、计算机科学等领域的技术论文，注重算法理解和实现细节。

### 开源项目
学习 GitHub 上的开源项目，注重代码结构、设计模式和实际应用。
